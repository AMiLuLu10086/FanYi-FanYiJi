# Round-Trip Amnesia（往返失忆症）

> **一个让中文出国 10 趟、回来可能忘了自己是谁的 AI 语言玩具。**

输入一句中文，让 AI 把它翻成英文，再翻回中文，反复折腾。你可以看着一句话从「我认识每个字」，逐渐走向「每个字都认识我，但我们不熟」。

这是一个 **AI 产品设计小实验**：把机器翻译里的语义偏差，做成可以围观、对比和分享的文字传话游戏。默认往返 10 轮、共 20 次翻译；句子每出去一圈就忘一点，回来常常已经失忆——**Round-Trip Amnesia**，往返失忆症，名字就是这么来的。

**玩法：放进去一句人话 → 围观 AI 来回传话 → 看看回来的是哪位。**

## 先看一只门铃是怎么走丢的

下面摘自项目本地的一次真实运行，保留出发前的原句和每轮翻回来的中文：

| 进度 | 句子现状 |
|---|---|
| 出发前 | 他称，他制作了一个 WiFi 门铃。 |
| 第 1 轮 | 他说他做了无线网络铃 |
| 第 2 轮 | 他说他做了无线铃 |
| 第 3 轮 | 他说他做了无线铃声 |
| 第 4 轮 | 他说他把收音机铃响了 |
| 第 5 轮 | 他说他拨打无线电了 |

门铃出门的时候还是智能家居，回来已经转行搞通信了。

这条记录跑了 5 轮，也就是 10 次翻译。它展示的是一次实际结果；换句话、换参数或再跑一次，都可能走向别的剧情。也可能十分无聊——AI 没有签每轮必须逗笑你的劳动合同。

## 为什么做这个：让 AI 的偏差变成游乐设施

翻译来回几次，词义、语气、主语和句子结构都可能慢慢走样。这个项目想把这种变化摆到眼前：你不用懂模型，也能看见一句话如何在两种语言之间被重新理解。

它适合想拿自己的句子试试运气的人，也适合对 AI 的语言处理有点好奇、但暂时不想读论文的人。输入可以很日常：一句吐槽、一句情话、一句公司黑话。素材越熟悉，变化越容易被发现。

产品想做出的体验很简单：

- **几秒看懂玩法。** 一个输入框，一个轮数，一个开始按钮，自己的句子就是游戏素材。
- **过程有东西可看。** 每轮中英文都展开，能找到意思从哪一步开始拐弯。
- **看完有东西可带走。** 原句、结果和全过程都能复制，也能导出 Markdown，拿去和朋友一起围观。

这里的设计假设是：**人们愿意看的，可能不只是一个离谱结果，还有它一路变离谱的过程。**

## AI 产品设计：胡闹也得有个章法

### 1. 把过程做成主角：笑点需要案发现场

页面保留三层信息：**起始中文、最终中文、逐轮过程**。原句用绿色卡片展示，结果用蓝色卡片展示；每轮再并排放出原文与译文。

这样既能快速看前后差别，也能往下追：「门铃到底在哪一轮变成收音机的？」每轮结果陆续出现，把等待也变成体验的一部分。

### 2. 给不确定性留位置：惊喜可以有，失控也能停

当前默认使用随机采样，同一句话重跑时有机会出现不同结果。轮数可在 1–50 轮之间调整，也可以随时点击「停止」，保留已经完成的步骤；当前正在翻译的一步会先执行完。

轮数是用户控制实验长度的旋钮。更多轮不保证更好笑：它可能继续走样，也可能反复输出相近内容。发现精彩片段，或者觉得这部剧该完结了，都可以停。

另一种确定模式会在相同模型、参数和运行环境下更稳定地重复结果，适合追踪固定的变化路径。两种模式目前在配置文件里切换，页面上还没有模式开关。

### 3. 界面也说机翻腔：产品自己先进入状态

页面文案刻意带着一本正经的机翻味，比如「将被进行翻译的中文」「它已经被准备好了」「历史性的运行」。连复制成功都要说：「它已经被复制了。」

逐轮标题还会出现「尚在挣扎之中」「开始发生走样」「已经放弃抵抗」这样的旁白，让输入到输出的过程有一点小剧情。

这些旁白按轮次安排，负责气氛；它们不代表 AI 真的检测出了文本的情绪或走样程度。演出效果和模型能力，账要分开算。

### 4. 把判断权交给人：好不好笑，你说了算

每一步原样展示，不替模型润色，也不计算「离谱指数」、语义相似度或自动下结论。遇到疑似整段重复的输出，只加标签，保留现场。

用户可以自己找变化、自己挑笑点。系统如果抢先给一句话判个「搞笑程度 87 分」，反而像给冷笑话发了张绩效考核表。

### 5. 给结果留出口：围观结束，证据带走

每段文字都能单独复制，整次过程也能一次复制或导出 Markdown。完成、停止或出错后的记录会自动存到本地，之后可以从历史列表回看最近的运行。

这些功能让一次体验留下可回看的素材：既能分享最终结果，也能带上「它怎么变成这样的」全过程。

## AI 在哪里：两位翻译，互相接班

核心由两个 **OPUS-MT 神经机器翻译模型**承担，一个负责中→英，一个负责英→中。前一步的译文直接成为下一步的原文，偏差就有机会被继续传下去。

采用专门的翻译模型，能把玩法集中在反复翻译本身，也适合在本地运行。模型下载完成后，翻译无需联网，不需要 API Key，也不需要独立显卡。模型来源见文末的官方链接。

这个小实验探索的是：**怎样把 AI 输出的变化，设计成普通人也愿意参与的体验。** 模型负责传话，产品负责让你看懂它、控制它，再把有意思的片段带走。

## 可以拿什么进去折腾

下面是试玩题目，尚不对应任何预设结果。剧情请以 AI 现场发挥为准。

| 题材 | 可以试试的输入 |
|---|---|
| 打工人文学 | 这个需求很简单，今天下班前顺手做一下就行。 |
| 公司黑话 | 我们先对齐颗粒度，再形成闭环，最后抓一下落地。 |
| 含蓄表达 | 你人挺好的，就是我们可能不太合适。 |
| 日常拉扯 | 我不是那个意思，但你要这么理解，我也没办法。 |
| 日常吐槽 | 我的精神状态很好，只是暂时不想面对任何事物。 |

建议先用短句试玩。网页最多接受 2000 个字符，较长文本还可能触发模型的长度限制而被截断。

正式翻译请另请高明。这台机器主要负责让你和自己的句子重新认识一下。

## 想亲自玩：让它先上岗

需要 Python 3.11+。Windows 下双击 [run.bat](run.bat)，首次启动会创建环境、安装依赖、启动本地服务并打开浏览器。

首次使用需要联网下载两个模型，共约 624MB，Python 依赖还会额外占用磁盘空间。下载速度取决于网络，页面会显示模型状态；准备完成后就能开始玩。使用期间保持启动窗口打开。

如果浏览器先打开、服务还没准备好，稍等后刷新 [本地页面](http://127.0.0.1:8000)。

1. 输入一句中文，选轮数，点击「开始翻译」。默认 10 轮 = 20 次翻译。
2. 围观每轮的中英文结果，想结束时点击「停止」。
3. 复制有意思的片段，或导出 Markdown 保存全过程。
4. 以后从页面底部的历史列表重看最近的记录。

### 手动启动

### 调整玩法

参数集中在 [config.py](config.py)，修改后重启服务生效。

| 想调整什么 | 参数与当前默认值 |
|---|---|
| 随机还是确定 | `DECODE_MODE = "sample"`；改成 `"greedy"` 使用确定模式 |
| 随机程度 | `TEMPERATURE = 0.5`、`TOP_P = 0.95`；只在采样模式生效 |
| 固定采样结果 | `RANDOM_SEED = None`；设成整数可帮助在相同环境下复现 |
| 默认轮数与上限 | `DEFAULT_ROUNDS = 10`、`MAX_ROUNDS = 50` |
| 输入长度 | `MAX_INPUT_CHARS = 2000`、`MAX_INPUT_TOKENS = 512` |
| 模型与下载源 | `MODEL_ZH2EN`、`MODEL_EN2ZH`、`HF_ENDPOINT` |
| 本地服务地址 | `HOST = "127.0.0.1"`、`PORT = 8000` |

采样会引入额外变化，但也可能抽到相同结果；确定模式减少这种随机性，仍然可能发生翻译偏差。页面不会自动判断结果是否已经稳定。

运行记录位于 `runs/`，模型缓存位于 `models/`。想了解实现，可以从 [web/index.html](web/index.html)、[pipeline.py](pipeline.py) 和 [translator.py](translator.py) 看起。
